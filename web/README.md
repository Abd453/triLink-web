# 🎓 TriLink Web Application Workspace

This directory contains the Next.js frontend web application for the **TriLink Smart School Management System**.

For full project documentation, role breakdowns, environment configuration, and deployment guides, please refer to the [Root README](../README.md).

## Quick Start

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Run tests
npm run test

# Build production bundle
npm run build
```
