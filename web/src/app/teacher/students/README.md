# Teacher Students (`/teacher/students`)

Student list with click-to-expand analytics panel showing scores, attendance, and grade entries per class.

## Current Status

| Area | Status |
|---|---|
| Student roster | API-backed from active year, teacher class offerings, enrollments, and users |
| Exam score summary | API-backed from published exams and attempts |
| Attendance summary | API-backed from class attendance report |
| Grade details | API-backed per selected student |
